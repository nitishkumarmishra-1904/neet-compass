# NEET Compass

A lightweight NEET preparation dashboard for tracking topic progress, practice accuracy, mock-test scores, and an approximate rank estimate. Your dashboard data is stored in the browser's local storage.

## Open in VS Code

Clone this repository and open the folder in VS Code. Start the **Serve NEET Compass** task from **Terminal → Run Task**, then open <http://127.0.0.1:8000>.

Python is required to run the local web server.

## Open in GitHub Codespaces

From the repository's GitHub page, select **Code → Codespaces → Create codespace on main**. The Codespace forwards port 8000 and opens the site preview automatically.

## Rank estimate

The displayed rank is an estimate calculated from the percentile and candidate count entered for a mock test. It is not an official NEET rank prediction.
